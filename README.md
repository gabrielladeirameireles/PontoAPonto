# Ponto a Ponto — Portal de TI, Infraestrutura e Carreira

O **Ponto a Ponto** é um portal web estruturado para organizar conceitos fundamentais da Tecnologia da Informação, servir como guia de aprendizado contínuo e expor projetos práticos de software e infraestrutura.

O projeto foi reformulado para oferecer uma navegação fluida e direta, cobrindo desde os primeiros passos na carreira até diagnósticos práticos de rede e comandos de administração de sistemas.

---

## Estrutura do Portal

1. **Notícias & Mercado**: Panorama sobre tendências tecnológicas e linguagens ativas no mercado corporativo.
2. **Networking & Presença**: Práticas recomendadas para perfil profissional e uso do GitHub como portfólio.
3. **Ingresso em TI**: Trilha básica de lógica de programação, inglês técnico e fundamentos.
4. **Guia de Cursos Superiores**: Comparativo objetivo entre ADS, Ciência da Computação, Engenharia de Software, Sistemas de Informação e Redes.
5. **Linguagens de Programação**: Aplicações práticas de PHP, Python, JavaScript/TypeScript, Java e C#.
6. **Certificações**: Visão geral de qualificações reconhecidas (AWS SysOps, Cisco CCNA, LPI Essentials).
7. **Infraestrutura & Diagnóstico**: Leitura dinâmica de IP público e consulta de domínios.
8. **Guia Prático do Linux**: Passo a passo de instalação, hierarquia de diretórios (FHS) e permissões de arquivos (`chmod` / `chown`).
9. **Ferramentas de Rede**: Calculadora interativa de sub-redes IPv4 / CIDR.
10. **Projetos no GitHub**: Repositórios práticos integrados ao portfólio.

---

## Tecnologias Utilizadas

* **Frontend**: HTML5 Semântico, Tailwind CSS (via CDN) e JavaScript Vanilla.
* **Autenticação**: Supabase Auth (controle de acesso ao painel de edição do site).
* **Hospedagem**: GitHub Pages.
