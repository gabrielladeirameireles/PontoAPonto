Orientações fundamentais para iniciar a graduação e entender as diferenças de cada formação.

Primeiros Passos Recomendados Antes do Início das Aulas

Muitos estudantes ingressam no ensino superior sem contato prévio com a rotina da tecnologia. Construir uma base prévia diminui drasticamente a curva de aprendizado nos primeiros semestres:

1. Lógica e Algoritmos

Compreenda estruturas condicionais (if/else), laços de repetição (for/while) e manipulação de variáveis usando Python ou Portugol.

2. Inglês Técnico para TI

As melhores documentações oficiais, linguagens de programação, mensagens de erro e fóruns internacionais utilizam o inglês como padrão.

3. Definição do Perfil Profissional

Avalie se você possui maior afinidade com código (desenvolvimento), infraestrutura (redes/nuvem), gestão (projetos/negócios) ou análise de dados.

Análise Comparativa dos Cursos Superiores de TI

TECNÓLOGO (2,5 anos)

Análise e Desenvol. de Sistemas

Totalmente voltado para a prática de criação de software, banco de dados, desenvolvimento web e sistemas móveis. É a formação ideal para quem busca inserção rápida no mercado de trabalho.

• Foco: Programação e desenvolvimento.
• Atuação: Desenvolvedor Fullstack, Frontend, Backend.
BACHARELADO (4 a 5 anos)

Ciência da Computação

Formação científica e matemática profunda. Estuda como os computadores funcionam em baixo nível, algoritmos avançados, inteligência artificial, compiladores e teoria do processamento.

• Foco: Teoria científica e matemática.
• Atuação: Cientista de Dados, Pesquisador, Dev de Elite.
BACHARELADO (4 a 5 anos)

Engenharia de Software

Combina programação com processos e arquitetura de grande escala. Focado na qualidade do código, padrões de projeto (Design Patterns), testes automatizados e métodos ágeis.

• Foco: Arquitetura e processos robustos.
• Atuação: Arquiteto de Software, Tech Lead, Engenheiro.
BACHARELADO (4 anos)

Sistemas de Informação

Ponte entre a tecnologia da informação e a gestão corporativa. Aborda desenvolvimento e banco de dados aliados à administração de empresas, governança e processos de negócios.

• Foco: Negócios e tecnologia.
• Atuação: Gerente de Projetos, Analista de Negócios.
TECNÓLOGO (2,5 a 3 anos)

Redes & Defesa Cibernética

Focado na infraestrutura de comunicação de dados, roteadores, switches, servidores Linux/Windows, computação em nuvem, segurança defensiva e auditoria de sistemas.

• Foco: Infraestrutura, Nuvem e Segurança.
• Atuação: Administrador de Redes, Analista de Segurança.

3. Linguagens de Programação e Aplicação no Mercado

Panorama atual do mercado profissional para cada ecossistema de desenvolvimento.

Python

Líder absoluto em Inteligência Artificial, Ciência de Dados, Aprendizado de Máquina, Automação/Scripting de Redes e Backend web (Django/FastAPI). Possui sintaxe simples e alta demanda global.

JavaScript / TypeScript

A linguagem da web. Dominante no desenvolvimento Frontend (React, Vue, Angular) e amplamente utilizada no Backend (Node.js). O TypeScript adiciona tipagem estática e é o padrão corporativo atual.

Java & C# (.NET)

Pilares do desenvolvimento corporativo, grandes bancos, instituições governamentais e sistemas críticos. Oferecem altíssima estabilidade, escalabilidade e grande volume de vagas sênior.

C / C++

Essenciais para sistemas operacionais, drivers de hardware, sistemas embarcados, desenvolvimento de jogos e software de alto desempenho onde o controle direto de memória é indispensável.

Go (Golang) & Rust

Linguagens modernas foca em computação em nuvem, ferramentas de infraestrutura (Docker, Kubernetes) e microsserviços de alta concorrência. Rust destaca-se pela segurança de memória sem garbage collector.

SQL (Bancos de Dados Relacionais)

Conhecimento universal obrigatório para qualquer profissional de TI. Utilizado na estruturação, consulta e manipulação de dados em bancos PostgreSQL, MySQL, Oracle e SQL Server.

4. Principais Certificações da Indústria de TI

Qualificações reconhecidas globalmente no mercado corporativo e programas de capacitação gratuita.

AWS Certified SysOps Administrator – Associate

Página Oficial da AWS

Certificação de nível intermediário que valida a experiência técnica na implantação, gerenciamento, segurança e operação de sistemas escaláveis e tolerantes a falhas na infraestrutura AWS.

• Outras AWS recomendadas: AWS Certified Cloud Practitioner (Iniciante) e AWS Certified Solutions Architect (Projetos de Nuvem).

Cisco CCNA & Badges Gratuitos da Cisco Networking Academy

Plataforma Cisco Skills

O CCNA (Cisco Certified Network Associate) é o padrão ouro mundial para profissionais de redes. A plataforma Cisco Networking Academy disponibiliza cursos gratuitos com emissão de badges digitais em Redes, Segurança e Linux.

Microsoft Certified: Azure Fundamentals (AZ-900)

Comprova conhecimentos fundamentais sobre serviços de nuvem Microsoft Azure, governança e segurança. O portal Microsoft Learn oferece o treinamento 100% gratuito.

Oracle Cloud Infrastructure (OCI) Foundations

A Oracle disponibiliza cursos gratuitos em vídeo e exames de certificação sem custo para capacitação em infraestrutura OCI e banco de dados em nuvem.

5. Guia Prático e Conceitos do Linux

Passo a passo completo de instalação, estrutura de diretórios, permissões e processos.

Como Instalar o Linux: Preparação e Instalação

1. Criando o Pendrive Bootável

Baixe a imagem ISO da distribuição (ex: Ubuntu ou Linux Mint). Use o software gratuito Ventoy ou Rufus no Windows para gravar a ISO em um pendrive de no mínimo 8GB.

2. Configurando o Boot (BIOS/UEFI)

Reinicie o computador pressionando as teclas F2, F12, Del ou Esc para acessar a BIOS. Altere a ordem de inicialização (Boot Priority) para iniciar primeiro pelo pendrive USB.

3. Opções de Instalação

Você pode instalar em Dual Boot (lado a lado com o Windows), substituir totalmente o sistema, usar uma Máquina Virtual (VirtualBox) ou ativar o WSL2 no próprio Windows.

Estrutura de Diretórios (FHS)

/ (Raiz - Root) Diretório principal do sistema do qual derivam todas as pastas.
/etc Arquivos de configuração do sistema e de serviços (ex: network, ssh).
/var Dados variáveis: logs do sistema (`/var/log`), filas e sites (`/var/www`).
/home & /root Diretórios pessoais dos usuários comuns e do superusuário root.

Permissões de Arquivos (chmod & chown)

r (Read) = 4 w (Write) = 2 x (Execute) = 1

• chmod 755 script.sh: Dono lê/escreve/executa (7), Grupo e Outros leem/executam (5).

• chmod 644 texto.txt: Dono lê/escreve (6), Grupo e Outros apenas leem (4).

• chown usuario:grupo pasta/: Altera o proprietário e o grupo da pasta.

9. Resumos de Metodologias para Concursos

Síntese fundamentada nos guias oficiais mais cobrados pelas bancas.

PREDITIVO

Modelo em Cascata

Desenvolvimento linear em etapas (Requisitos -> Projeto -> Código -> Testes). Mudanças de escopo no final têm alto custo.

SCRUM GUIDE 2020

Framework Scrum

Papéis: Product Owner, Scrum Master e Developers. Não existe Gerente de Projetos no Scrum. As Sprints possuem timebox fixo.

KANBAN

Metodologia Kanban

Gestão de fluxo contínuo. Uso de WIP Limit (Work in Progress) para otimizar gargalos. Medição por Lead Time e Cycle Time.

LEAN

Lean Software

Focado na eliminação de desperdícios (Muda), no aprendizado contínuo e na entrega rápida de valor útil ao cliente.

ENGENHARIA

TDD

Desenvolvimento Guiado por Testes no ciclo Red -> Green -> Refactor. Os testes automatizados são criados antes do código.

XP

Extreme Programming

Pair Programming, Integração Contínua (CI) e Refatoração. Valores centrais: Comunicação, Simplicidade, Feedback e Coragem.
