Resumos de Metodologias para Concursos

Síntese fundamentada nos guias oficiais mais cobrados pelas bancas.

PREDITIVO

Modelo em Cascata

Desenvolvimento linear em etapas (Requisitos -> Projeto -> Código -> Testes). Mudanças de escopo no final têm alto custo.

SCRUM GUIDE 2020

Framework Scrum

Papéis: Product Owner, Scrum Master e Developers. Não existe Gerente de Projetos no Scrum. As Sprints possuem timebox fixo.

KANBAN

Metodologia Kanban

Gestão de fluxo contínuo. Uso de WIP Limit (Work in Progress) para otimizar gargalos. Medição por Lead Time e Cycle Time.

LEAN

Lean Software

Focado na eliminação de desperdícios (Muda), no aprendizado contínuo e na entrega rápida de valor útil ao cliente.

ENGENHARIA

TDD

Desenvolvimento Guiado por Testes no ciclo Red -> Green -> Refactor. Os testes automatizados são criados antes do código.

XP

Extreme Programming

Pair Programming, Integração Contínua (CI) e Refatoração. Valores centrais: Comunicação, Simplicidade, Feedback e Coragem.
